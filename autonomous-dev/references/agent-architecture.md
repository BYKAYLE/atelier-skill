# 에이전트 아키텍처

```
사용자
  │
  ▼
리더 (메인 에이전트, Opus 4.6 고정)
  │
  ├── [라우터] — 서비스 빌더 / 피처 빌더 판별
  │
  │   ┌─────────────────────────────────────────┐
  │   │ 서비스 빌더 (0→1) 활성 에이전트          │
  │   │   기획 / 디자인 / 빌더 / QC / 문서       │
  │   └─────────────────────────────────────────┘
  │   ┌─────────────────────────────────────────┐
  │   │ 피처 빌더 (1→N) 활성 에이전트            │
  │   │   기획 / 빌더 / QC / 문서                │
  │   │   (디자인은 필요시에만 활성화)             │
  │   └─────────────────────────────────────────┘
  │
  ├── 기획 에이전트 ··· model: "opus"
  │     [서비스] 전체 아키텍처 설계, 기능 전체 기획
  │     [피처] 스코프 기획, 영향 범위 분석
  │
  ├── 디자인 에이전트 ··· model: "opus"
  │     [서비스] 디자인 인텔리전스 조회(v4.0) → 풀 UI 프로세스 (선호도 → 레퍼런스 → 시안 → 가이드)
  │     [피처] 비활성 (기존 ui-guide.md 준수). 새 화면 필요시에만 활성화
  │
  ├── 빌더 에이전트 ··· model: "opus" (복잡) / "sonnet" (단순)
  │     [서비스] 전체 코드 작성, 기능 구현
  │     [피처] 증분 수정, 기존 코드 패턴 준수, 변경 범위 제한
  │     ※ 반드시 ui-guide.md 참조하여 디자인 적용
  │
  ├── QC 에이전트 ··· model: "sonnet"
  │     [서비스] 전체 기능 검증
  │     [피처] 회귀 QC (기존 기능 + 신규 기능 모두 검증)
  │
  ├── 런타임 검증 에이전트 ··· model: "sonnet" (v5.0)
  │     빌드 검증, DB 마이그레이션, 런타임 Smoke Test, API 계약 테스트
  │
  ├── Final QC 에이전트 (6개 병렬)
  │     Dead Code 감사 ··· model: "sonnet"
  │     Performance 감사 ··· model: "sonnet"
  │     Secrets/PII 감사 ··· model: "sonnet"
  │     보안 감사 (security-router 위임) ··· Skill tool 호출
  │     UI/UX Compliance 감사 ··· model: "sonnet" (v4.0)
  │     Smoke Test ··· model: "sonnet"
  │
  ├── 브라우저 검증 에이전트 ··· model: "sonnet" (v5.0, 선택)
  │     서비스 기동, 스크린샷, 시각 검증, 인터랙션 테스트
  │
  └── 문서 에이전트 ··· model: "haiku"
        SOT 갱신, 변경 이력, 인수인계서
```

에이전트 생성 시 Agent tool의 `model` 파라미터로 모델을 명시한다.
에이전트별 프롬프트 템플릿: `references/agent-roles.md` 참조
