## Adding a New Skill

1. 위 테이블에 한 줄 추가
2. Domain → Skill Mapping에 해당 카테고리 추가 (또는 기존 카테고리에 대안으로 등록)
3. 테스트 위임 1회 실행하여 라우팅 확인
