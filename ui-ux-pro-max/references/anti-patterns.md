# UI/UX 안티패턴 모음

## 1. 다크 패턴 (Dark Patterns)

사용자를 속이거나 의도와 다른 행동을 유도하는 패턴. **절대 구현하지 않는다.**

### 1.1 Confirmshaming (수치심 유발)

거절 옵션을 부정적으로 표현하여 수락을 유도.

```
나쁜 예:
[뉴스레터 구독] "네, 최신 소식 받기"
                "아니요, 저는 뒤처지겠습니다"

좋은 예:
[뉴스레터 구독] "구독하기"
                "나중에 하기"
```

### 1.2 Hidden Cost (숨겨진 비용)

결제 마지막 단계에서 추가 비용이 나타남.

```
나쁜 예:
상품: ₩10,000 → 결제 단계에서 배송비 ₩3,000 + 수수료 ₩500 추가

좋은 예:
상품 목록부터 "₩10,000 (배송비 ₩3,000)" 표시
장바구니에서 총액 ₩13,500 명확히 표시
```

### 1.3 Roach Motel (바퀴벌레 모텔)

가입은 쉽지만 탈퇴는 극도로 어려운 패턴.

```
나쁜 예:
가입: 3초 (소셜 로그인)
탈퇴: 설정 > 계정 > 고급 > 계정관리 > 탈퇴 > 전화문의 필요

좋은 예:
설정 > 계정 > "계정 삭제" 버튼 → 확인 → 완료
```

### 1.4 Trick Questions (속임수 질문)

혼란스러운 이중부정, 반대 의미의 체크박스.

```
나쁜 예:
☑ 마케팅 이메일을 수신하지 않는 것을 원하지 않습니다

좋은 예:
☐ 마케팅 이메일 수신에 동의합니다
```

### 1.5 Bait and Switch (미끼와 교체)

한 가지를 기대하게 하고 다른 결과를 제공.

```
나쁜 예:
"무료 다운로드" 클릭 → 유료 구독 페이지로 이동

좋은 예:
무료 기능과 유료 기능을 명확히 구분
```

### 1.6 Forced Continuity (강제 연속)

무료 체험 후 자동 유료 전환 (경고 없이).

```
나쁜 예:
무료 체험 종료 → 자동 결제 (사전 알림 없음)

좋은 예:
무료 체험 3일 전 이메일 + 앱 내 알림
"체험이 곧 종료됩니다. 결제 정보를 확인하세요."
```

### 1.7 Misdirection (주의 분산)

중요한 정보에서 시선을 다른 곳으로 유도.

```
나쁜 예:
[화려한 할인 배너]                [작은 회색 텍스트: 12개월 약정 필수]
[지금 구매!!! 80% 할인]

좋은 예:
할인 가격과 조건을 같은 시각적 비중으로 표시
```

### 1.8 Preselection (사전 선택)

사용자가 원하지 않을 수 있는 옵션을 미리 체크.

```
나쁜 예:
☑ 프리미엄 보험 추가 (₩5,000/월)
☑ 뉴스레터 수신 동의

좋은 예:
☐ 프리미엄 보험 추가 (₩5,000/월) - 선택 사항
☐ 뉴스레터 수신 동의 - 선택 사항
```

### 1.9 Privacy Zuckering

개인정보를 의도보다 많이 공유하도록 유도.

```
나쁜 예:
기본 프로필 공개 범위: "전체 공개"
위치 공유: 기본 "항상"

좋은 예:
기본 공개 범위: "친구만"
위치 공유: 기본 "사용 안 함" + 필요 시 요청
```

## 2. 인지 과부하 유발 패턴

### 2.1 과도한 선택지

| 문제 | 해결 |
|------|------|
| 15개 이상 네비게이션 항목 | 카테고리 그룹핑 + 점진적 공개 |
| 20개 이상 드롭다운 옵션 | 검색 + 최근/인기 항목 우선 표시 |
| 한 화면에 CTA 3개 이상 | 1차 CTA 1개 + 2차 최대 1개 |
| 설정 페이지 모든 옵션 펼침 | 섹션 분리 + 기본값 제공 |
| 대시보드 위젯 10개+ | 사용 빈도에 따라 우선순위, 커스터마이징 |

### 2.2 정보 과밀

| 문제 | 해결 |
|------|------|
| 여백 없는 빽빽한 레이아웃 | 8pt 그리드 기반 여백 |
| 모든 데이터를 한 번에 표시 | 요약 + "상세 보기" |
| 긴 폼을 한 페이지에 | 멀티스텝 위저드 (3~5단계) |
| 작은 폰트로 많은 텍스트 | 최소 14px + 줄 높이 1.5 |
| 레이블 없는 아이콘만 | 아이콘 + 텍스트 또는 툴팁 |

### 2.3 일관성 부재

| 문제 | 해결 |
|------|------|
| 페이지마다 다른 버튼 스타일 | 디자인 토큰 + 컴포넌트 라이브러리 |
| 같은 기능에 다른 아이콘 | 아이콘 세트 통일 |
| 간격이 제각각 | 스페이싱 스케일 준수 |
| 색상이 제각각 | 색상 팔레트 준수 |
| 폰트 3개 이상 혼용 | 최대 2개 (제목+본문) |

## 3. 접근성 위반 패턴

| 안티패턴 | 위반 기준 | 해결 |
|---------|----------|------|
| 회색 텍스트 on 밝은 배경 | WCAG 1.4.3 (대비비) | 최소 4.5:1 대비 확인 |
| 색상만으로 에러 표시 | WCAG 1.4.1 (색상 사용) | 아이콘 + 텍스트 추가 |
| 포커스 스타일 제거 `outline: none` | WCAG 2.4.7 (포커스 표시) | `focus-visible` 사용 |
| img alt 누락 | WCAG 1.1.1 (비텍스트) | 모든 img에 alt |
| 자동 재생 비디오+소리 | WCAG 1.4.2 (오디오) | 음소거 기본 + 재생 버튼 |
| label 없는 input | WCAG 3.3.2 (레이블) | label + for 연결 |
| 키보드로 접근 불가 | WCAG 2.1.1 (키보드) | tabindex, keydown 핸들러 |
| 움직임 멈출 수 없음 | WCAG 2.3.1 (번쩍임) | prefers-reduced-motion |
| 시간 제한 경고 없음 | WCAG 2.2.1 (타이밍) | 연장/해제 옵션 |
| maximum-scale=1 | 접근성 위반 | 삭제 (사용자가 줌 가능하게) |

```css
/* 절대 하지 말 것 */
*:focus { outline: none; }  /* 포커스 스타일 제거 금지 */

/* 올바른 방법 */
*:focus-visible {
  outline: 2px solid #3B82F6;
  outline-offset: 2px;
}
```

```html
<!-- 절대 하지 말 것 -->
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">

<!-- 올바른 방법 -->
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## 4. 모바일 안티패턴

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 터치 타겟 30px 미만 | 오탭 빈발 | 최소 44x44px |
| 하단에 닿지 않는 중요 버튼 | 한 손 사용 어려움 | 하단 고정 CTA |
| 데스크톱 UI 그대로 축소 | 읽기/터치 어려움 | Mobile-First 설계 |
| 가로 스크롤 | 콘텐츠 발견 어려움 | 100% 너비 콘텐츠 |
| 팝업이 화면 전체 차단 | 닫기 어려움 | 바텀시트 또는 작은 배너 |
| 16px 미만 입력 폰트 | iOS 자동 줌 | font-size: 16px 이상 |
| 호버에만 의존하는 인터랙션 | 모바일에 호버 없음 | 탭/롱프레스 대체 |
| Safe Area 미고려 | 노치/홈바에 콘텐츠 가림 | env(safe-area-inset-*) |
| 스와이프 제스처 충돌 | 브라우저 뒤로가기와 충돌 | 제스처 영역 제한 |
| 무한 스크롤 + 접근 불가 푸터 | 푸터 정보 접근 불가 | 푸터 정보를 다른 곳에도 배치 |

## 5. 폼 안티패턴

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 불필요한 필수 필드 | 이탈률 증가 | 최소한의 필수 필드만 |
| 인라인 레이블 (placeholder만) | 입력 시 레이블 사라짐 | 상단 레이블 사용 |
| 에러를 제출 후에만 표시 | 재입력 번거로움 | 실시간 유효성 검사 |
| 에러 메시지가 기술적 | 사용자 이해 불가 | 사용자 언어로 작성 |
| 비밀번호 규칙 사전 미표시 | 시행착오 | 규칙을 미리 표시 + 실시간 체크 |
| 캡차가 너무 어려움 | 이탈 | reCAPTCHA v3 또는 간단한 챌린지 |
| 전화번호 형식 강제 | 국가마다 다름 | 자유 입력 + 자동 포맷 |
| 카드번호 한 칸 입력 | 긴 숫자 입력 어려움 | 4자리씩 분리 또는 자동 간격 |
| Reset/Clear 버튼 | 실수로 입력 내용 삭제 | Reset 버튼 제거 |
| Submit 더블 클릭 방지 없음 | 중복 제출 | 로딩 상태 + disabled |

```css
/* 잘못된 플레이스홀더만 사용 */
/* <input placeholder="이메일"> ← 레이블 없음 */

/* 올바른 방법 */
/* <label for="email">이메일</label>
   <input id="email" placeholder="name@example.com"> */
```

## 7. 데이터 시각화 안티패턴

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 3D 파이 차트 | 비율 왜곡 | 2D 파이/도넛 또는 바 차트 |
| Y축 0에서 시작 안 함 | 차이 과장 | Y축 0부터 시작 (예외: 주식) |
| 범례만 있고 직접 라벨 없음 | 눈을 왕복해야 함 | 차트에 직접 라벨 |
| 색상만으로 구분 | 색맹 문제 | 패턴, 모양, 직접 라벨 |
| 너무 많은 카테고리 (10+) | 구분 불가 | 상위 5~7개 + "기타" |
| 이중 Y축 | 혼란 | 차트 분리 또는 정규화 |
| 적절하지 않은 차트 유형 | 오해 유발 | 데이터에 맞는 차트 선택 |
| 숫자 포맷 없음 | 읽기 어려움 | 콤마, 단위, 약어(K/M/B) |
| 인터랙션 없는 정적 차트 | 상세 탐색 불가 | 호버 툴팁, 클릭 드릴다운 |
| 업데이트 시간 미표시 | 데이터 신뢰도 불확실 | "마지막 업데이트: HH:MM" |

```css
/* 차트 색상 — 색맹 안전 팔레트 */
:root {
  --chart-1: #2563EB; /* 파랑 */
  --chart-2: #DC2626; /* 빨강 */
  --chart-3: #059669; /* 녹색 — 밝기가 다름 */
  --chart-4: #D97706; /* 주황 */
  --chart-5: #7C3AED; /* 보라 */
  --chart-6: #0891B2; /* 청록 */
}
```

## 10. 마이크로인터랙션 안티패턴

### 10.1 피드백 부재

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 클릭해도 반응 없음 | 동작 여부 모름 | 즉각적 시각 피드백 (active 상태) |
| 토글 전환 시 변화 안 보임 | 현재 상태 파악 불가 | 색상 + 위치 + 레이블 동시 변경 |
| 드래그 가능 여부 알 수 없음 | 기능 발견 불가 | grab 커서 + hover 시 핸들 표시 |
| 복사 완료 피드백 없음 | 복사 성공 여부 모름 | "복사됨" 토스트 또는 아이콘 변경 |
| 저장 완료 표시 없음 | 저장 여부 불확실 | "저장됨" 텍스트 또는 체크 아이콘 |

```css
/* 나쁜 예: 클릭해도 아무 반응 없는 버튼 */
.btn { cursor: pointer; }

/* 좋은 예: 즉각적 피드백 */
.btn {
  cursor: pointer;
  transition: all 0.15s ease;
}
.btn:hover {
  background-color: var(--primary-hover);
  transform: translateY(-1px);
}
.btn:active {
  transform: translateY(0) scale(0.98);
}
.btn:focus-visible {
  outline: 2px solid var(--primary);
  outline-offset: 2px;
}
```

### 10.2 과도한 애니메이션

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 모든 요소에 bounce 효과 | 산만함, 전문성 저하 | 핵심 인터랙션에만 subtle 모션 |
| 300ms 이상 로딩 스피너 | 지연 느낌 | 150~250ms 이내 반응 |
| 페이지 전환마다 화려한 효과 | 사용 속도 저하 | fade/slide 200~300ms 이내 |
| 스크롤 하이재킹 | 스크롤 제어권 빼앗김 | 자연 스크롤 유지 |
| 자동 캐러셀 (멈출 수 없음) | 읽는 중에 넘어감 | 수동 제어 + 호버 시 정지 |

```css
/* 나쁜 예: 스크롤 하이재킹 */
html { scroll-snap-type: y mandatory; } /* 전체 페이지에 강제 스냅 */
section { scroll-snap-align: start; height: 100vh; }

/* 좋은 예: 선택적 스냅 (갤러리 같은 곳에만) */
.gallery {
  scroll-snap-type: x mandatory;
  overflow-x: auto;
}
.gallery-item { scroll-snap-align: center; }
```

### 10.3 상태 표시 미흡

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 활성 탭 구분 없음 | 현재 위치 모름 | 활성 탭에 색상 + 밑줄 |

| 온라인/오프라인 구분 없음 | 네트워크 상태 모름 | 연결 상태 표시 바 |

}

## 14. 국제화(i18n) 안티패턴

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 하드코딩된 문자열 | 번역 불가 | i18n 라이브러리 사용 |
| 고정 너비 버튼 | 번역 시 텍스트 잘림 | min-width + padding 기반 |
| 날짜 형식 고정 (MM/DD/YYYY) | 국가마다 다름 | Intl.DateTimeFormat 사용 |
| 통화 기호 고정 ($) | 국가마다 다름 | Intl.NumberFormat 사용 |
| RTL 언어 미고려 | 아랍어/히브리어 레이아웃 깨짐 | logical properties (inline-start 등) |
| 문자열 연결로 문장 구성 | 어순 다른 언어에서 깨짐 | 템플릿 변수 사용 |
| 아이콘에 문화적 의미 무시 | 오해 가능 | 문화 중립적 아이콘 선택 |

```css
/* 나쁜 예: 물리적 방향 속성 */
.sidebar { margin-left: 16px; padding-right: 24px; }

/* 좋은 예: 논리적 방향 속성 (RTL 자동 대응) */
.sidebar { margin-inline-start: 16px; padding-inline-end: 24px; }
```

```css
/* RTL 대응 Flexbox */
.nav { display: flex; /* RTL 시 자동 역순 */ }

/* RTL 대응 Grid */
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  /* RTL 시 자동으로 사이드바가 오른쪽에 */
}
```

## 16. 안티패턴 자가진단 체크리스트

프로젝트 완성 후 아래를 확인:

```
[ ] 사용자를 속이는 패턴이 없는가 (다크 패턴)
[ ] 한 화면에 정보가 과밀하지 않은가 (인지 부하)
[ ] 색상만으로 정보를 구분하는 곳이 없는가 (접근성)
[ ] 모바일에서 터치 타겟이 44px 이상인가 (모바일)
[ ] 폼의 필수 필드가 최소한인가 (폼)
[ ] 현재 위치가 항상 표시되는가 (네비게이션)
[ ] 로딩 상태가 표시되는가 (성능)
[ ] 에러 메시지가 사용자 언어인가 (콘텐츠)
[ ] 빈 상태에 안내가 있는가 (콘텐츠)
[ ] 키보드로 모든 기능에 접근 가능한가 (접근성)
[ ] outline: none이 없는가 (접근성)
[ ] maximum-scale=1이 없는가 (접근성)
```
