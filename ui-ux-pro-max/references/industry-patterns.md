# 산업별 UI 패턴 백과사전

## 1. SaaS 대시보드

### 필수 패턴
- 사이드바 네비게이션 (축소/확장)
- KPI 카드 상단 배치 (4열)
- 차트/그래프 영역 (2열)
- 데이터 테이블 (정렬, 필터, 페이지네이션)
- Command Palette (Cmd+K)
- 알림 센터
- 사용자 프로필/설정 드롭다운
- 빈 상태 화면 (온보딩 유도)

### 추천 레이아웃
```
사이드바(240px) + TopBar(64px) + 메인 콘텐츠
KPI: 4열 그리드
차트: 2열 그리드
테이블: 전체 너비
```

### 색상 톤
- 배경: 밝은 회색 (#F8FAFC)
- 카드: 순백 (#FFFFFF)
- Primary: 파랑 계열 (#3B82F6)
- 데이터 시각화: 6~8색 차트 팔레트
- 분위기: 깔끔, 전문적, 데이터 중심

### 참고 서비스: Vercel, Linear, Notion, Stripe Dashboard

### 안티패턴
- 한 화면에 KPI 10개 이상
- 차트에 범례 없이 색상만으로 구분
- 사이드바 메뉴 항목 15개 이상 (계층 없이)
- 실시간 데이터를 자동 새로고침 없이 표시

## 2. 핀테크 / 뱅킹

### 필수 패턴
- 잔액/포트폴리오 요약 (큰 숫자, 변동률)
- 거래 내역 리스트 (무한 스크롤 + 필터)
- 이체/송금 플로우 (스텝 위저드)
- 본인 인증 단계 (OTP, 생체 인증)
- 보안 알림 / 이상 거래 감지
- 차트 (자산 추이, 포트폴리오 분배)
- 카드 관리 (카드 이미지 + 잠금/해제)

### 추천 레이아웃
```
모바일: 탭바(홈/이체/내역/더보기)
데스크톱: 사이드바 + 카드 중심 대시보드
이체 플로우: 싱글 컬럼 스텝 위저드
```

### 색상 톤
- Primary: 네이비/짙은 파랑 (#1E3A5F)
- 상승: 녹색 (#10B981), 하락: 빨강 (#EF4444)
- 배경: 순백 또는 아주 밝은 회색
- 분위기: 신뢰, 안정, 보안

### 참고 서비스: 토스, 카카오뱅크, Robinhood, Revolut

### 안티패턴
- 잔액을 작은 폰트로 표시
- 이체 시 확인 단계 없음
- 거래 내역에 카테고리 아이콘 없음
- 보안 관련 액션에 시각적 강조 없음

## 3. 이커머스

### 필수 패턴
- 상품 목록 (그리드/리스트 뷰 전환)
- 상품 카드 (이미지, 가격, 평점, 할인)
- 상품 상세 (이미지 갤러리, 옵션, 리뷰, 관련 상품)
- 장바구니 (수량 변경, 삭제, 소계)
- 결제 플로우 (주소 → 배송 → 결제 → 확인)
- 검색 + 필터 (카테고리, 가격, 평점, 정렬)
- 위시리스트
- 주문 추적

### 추천 레이아웃
```
상품 목록: auto-fill 그리드 (min 240px)
상품 상세: 이미지(좌 50%) + 정보(우 50%)
장바구니: 테이블 또는 카드 리스트
결제: 싱글 컬럼 스텝
모바일: 상단 검색 + 카테고리 탭 + 2열 그리드
```

### 색상 톤
- Primary: 검정 또는 브랜드 컬러
- CTA (장바구니 추가): 강한 색상 (#F97316 주황 또는 브랜드)
- 할인: 빨강 (#EF4444)
- 무료배송: 녹색 (#10B981)
- 배경: 흰색 (상품에 집중)

### 참고 서비스: 쿠팡, 무신사, Amazon, Shopify

### 안티패턴
- 상품 이미지 저품질/불균일한 비율
- CTA(장바구니) 버튼이 눈에 안 띔
- 배송비가 결제 마지막에 공개 (Hidden Cost)
- 필터 결과가 0건인데 안내 없음
- 모바일에서 가격 비교 어려운 레이아웃

## 4. 헬스케어 / 메디컬

### 필수 패턴
- 환자 차트/프로필 (기본 정보, 진료 이력)
- 예약 캘린더 (시간 슬롯 선택)
- 대시보드 (일정, 대기 환자, 알림)
- 처방전/검사 결과 표시
- 진료 기록 타임라인
- 접근성 최우선 (WCAG AA 필수)

### 추천 레이아웃
```
의사용: 사이드바 + 환자 리스트(좌) + 차트(우) Split View
환자용: 탭바(홈/예약/기록/설정) 모바일 중심
예약: 캘린더 뷰 + 시간 슬롯 그리드
```

### 색상 톤
- Primary: 하늘 파랑 (#0EA5E9) — 청결, 신뢰
- Secondary: 녹색 (#10B981) — 건강
- 배경: 매우 밝은 파랑 (#F0F9FF) 또는 순백
- 분위기: 깨끗, 신뢰, 차분

### 안티패턴
- 의료 데이터에 색상만으로 구분 (색맹 미고려)
- 약물 알레르기 경고가 눈에 안 띔
- 폰트 크기가 작음 (시니어 사용자 고려 필요)
- 예약 확인/취소 절차가 불명확

---

## 5. 교육 / LMS

### 필수 패턴
- 강의 목록 (카드 그리드, 진행률 표시)
- 강의 상세 (설명, 커리큘럼, 리뷰, 가격)
- 강의 수강 화면 (비디오 + 사이드바 목록)
- 진도 추적 (프로그레스 바, 완료 뱃지)
- 퀴즈/과제 제출
- 대시보드 (수강 중, 추천, 성과)
- 인증서/뱃지 시스템

### 추천 레이아웃
```
강의 목록: auto-fill 카드 그리드
수강 화면: 비디오(메인 70%) + 사이드바(목록 30%)
진도: 상단 프로그레스 + 체크리스트
퀴즈: 싱글 컬럼, 한 문제씩
```

### 색상 톤
- Primary: 인디고/보라 (#4F46E5) — 학습, 집중
- 진행률: 녹색 (#10B981)
- 뱃지/보상: 금색 (#F59E0B)
- 배경: 밝은 보라 톤 (#F5F3FF)
- 분위기: 집중, 성취, 동기 부여

### 안티패턴
- 진행률이 보이지 않음
- 비디오 플레이어가 너무 작음
- 목록에서 수강 완료/미완료 구분 없음
- 검색/필터가 없는 긴 강의 목록

---

## 6. 소셜 / 커뮤니티

### 필수 패턴
- 피드 (무한 스크롤, 당겨서 새로고침)
- 포스트 카드 (프로필, 콘텐츠, 좋아요/댓글/공유)
- 프로필 페이지 (헤더 이미지, 아바타, 소개, 탭)
- 댓글/답글 스레드
- 메시징 (채팅 버블, 읽음 확인)
- 알림 (활동 피드)
- 검색 (사람, 콘텐츠, 해시태그)
- 스토리/릴

### 추천 레이아웃
```
피드: 싱글 컬럼 (max 600px) 중앙 정렬
프로필: 헤더(커버+아바타) + 탭(포스트/미디어/좋아요)
메시징: Split View (대화 목록 + 채팅)
모바일: 탭바(홈/검색/만들기/알림/프로필)
```

### 색상 톤
- Primary: 브랜드 색상 (보라 #8B5CF6 또는 파랑)
- 좋아요: 빨강/핑크 (#EC4899)
- 배경: 밝은 회색 또는 순백
- 분위기: 활기, 연결, 개인적

### 안티패턴
- 피드 로딩이 느리고 스켈레톤 없음
- 좋아요/반응 버튼 터치 타겟이 작음
- 무한 스크롤에서 "맨 위로" 버튼 없음
- 댓글 스레드 깊이 제한 없음 (읽기 어려움)

---

## 7. 미디어 / 콘텐츠

### 필수 패턴
- 콘텐츠 피드 (카드 그리드 또는 리스트)
- 카테고리 필터/탭
- 콘텐츠 상세 (텍스트, 이미지, 비디오)
- 갤러리/슬라이더
- 비디오 플레이어 (커스텀 컨트롤)
- 북마크/저장
- 공유 기능
- 관련 콘텐츠 추천

### 추천 레이아웃
```
뉴스: 히어로 기사 + 그리드 (피처드 큰 카드 + 작은 카드)
갤러리: Masonry 또는 정사각형 그리드
비디오: 16:9 메인 + 사이드바 재생 목록
기사: 싱글 컬럼 (max 680px), 가독성 최적
```

### 색상 톤
- 뉴스: 빨강 + 검정 + 흰색 (긴급, 권위)
- 비디오: 다크 테마 기본 (#0F172A)
- 매거진: 흰색 + 세리프 폰트 + 넓은 여백
- 분위기: 몰입, 콘텐츠 중심

---

## 8. 부동산

### 필수 패턴
- 매물 검색 (필터: 위치, 가격, 면적, 유형)
- 지도 통합 (매물 핀 + 클러스터링)
- 매물 카드 (대표 사진, 가격, 면적, 위치)
- 매물 상세 (사진 갤러리, 평면도, 상세 정보, 주변 시설)
- 비교 기능 (매물 2~3개 나란히)
- 관심 매물 저장
- 중개사 연락

### 추천 레이아웃
```
검색: 좌측 지도(60%) + 우측 리스트(40%) 또는 전환
상세: 갤러리(상단) + 정보 탭(하단)
모바일: 지도/리스트 탭 전환
```

### 색상 톤
- Primary: 진한 파랑 (#1D4ED8) — 신뢰
- 가격: 검정 볼드
- 배경: 밝은 회색 + 흰색 카드
- 지도: 브랜드 컬러 핀

---

## 9. 여행 / 예약

### 필수 패턴
- 검색 폼 (목적지, 날짜, 인원)
- 검색 결과 (카드 + 필터 + 정렬)
- 상세 페이지 (사진, 리뷰, 지도, 가격)
- 예약 플로우 (날짜 선택 → 옵션 → 결제)
- 캘린더 (날짜 범위 선택, 가격 표시)
- 리뷰/평점
- 일정 관리

### 추천 레이아웃
```
검색: 전체 너비 검색바 + 결과 그리드
상세: 사진 갤러리(상단) + 2컬럼(정보/예약)
예약: 싱글 컬럼 스텝
모바일: 하단 고정 가격+예약 CTA
```

### 색상 톤
- Primary: 청록 (#0891B2) — 바다, 여행
- Accent: 주황 (#F97316) — 따뜻함
- 별점: 금색 (#F59E0B)
- 배경: 매우 밝은 청록 (#ECFEFF)
- 분위기: 모험, 기대, 발견

---

## 10. 음식 / 배달

### 필수 패턴
- 음식점 목록 (카드, 평점, 배달 시간, 최소 주문)
- 메뉴 (카테고리별 + 사진 + 가격 + 옵션)
- 장바구니 (하단 플로팅 바, 요약)
- 주문 플로우 (장바구니 → 주소 → 결제)
- 주문 추적 (지도 + 상태 스텝)
- 리뷰/평점
- 즐겨찾기 음식점

### 추천 레이아웃
```
홈: 검색 + 카테고리 아이콘 + 추천 음식점 카드
메뉴: 좌측 카테고리 고정 + 스크롤 메뉴 아이템
장바구니: 하단 플로팅 바 + 풀 장바구니 바텀시트
추적: 상단 지도 + 하단 상태 스텝
```

### 색상 톤
- Primary: 빨강 (#EF4444) — 식욕
- Accent: 주황 (#F97316) — 따뜻함
- 배경: 매우 밝은 크림 (#FFFBEB)
- 분위기: 따뜻함, 맛있음, 빠름

### 안티패턴
- 메뉴 사진이 없거나 품질 낮음
- 장바구니 총액이 보이지 않음
- 배달 예상 시간 미표시
- 주문 추적 상태 업데이트 없음

---

## 11. CRM / 어드민

### 필수 패턴
- 데이터 테이블 (정렬, 필터, 검색, 일괄 작업)
- CRUD 폼 (생성/읽기/수정/삭제)
- 상세 패널 (사이드 패널 또는 모달)
- 대시보드 (KPI + 차트 + 최근 활동)
- 사이드바 내비게이션 (멀티레벨)
- 검색 + 고급 필터
- 내보내기 (CSV/PDF)
- 감사 로그

### 추천 레이아웃
```
기본: 사이드바 + TopBar + 테이블 중심
상세: 테이블 행 클릭 → 우측 패널(400px)
생성: 모달 또는 새 페이지 (폼 복잡도에 따라)
대시보드: KPI(4열) + 차트(2열) + 최근 활동(전체 너비)
```

### 색상 톤
- Primary: 인디고 (#4F46E5) — 전문적
- 배경: 밝은 회색 (#F1F5F9)
- 테이블: 흰색 배경 + 미세한 행 구분선
- 분위기: 효율적, 체계적, 전문적

---

## 12. 프로젝트 관리

### 필수 패턴
- 칸반 보드 (드래그 앤 드롭 컬럼)
- 리스트 뷰 (작업 체크리스트)
- 타임라인/간트 차트
- 작업 상세 (모달 또는 사이드 패널)
- 멤버 할당 (아바타 스택)
- 태그/라벨 시스템
- 필터/그룹핑
- 진행률 표시

### 추천 레이아웃
```
칸반: 가로 스크롤 컬럼 (To Do/In Progress/Review/Done)
리스트: 그룹핑 가능한 테이블/리스트
타임라인: 가로 타임라인 + 세로 작업 행
작업 상세: 우측 패널(480px) 또는 모달
```

### 색상 톤
- 상태: Todo(#6B7280), In Progress(#3B82F6), Review(#F59E0B), Done(#10B981)
- 우선순위: Urgent(#EF4444), High(#F97316), Medium(#EAB308), Low(#6B7280)
- Primary: 보라-파랑 (#6366F1)
- 분위기: 체계적, 시각적 명확함

### 참고 서비스: Linear, Notion, Jira, Asana

---

## 13. 분석 / BI

### 필수 패턴
- 대시보드 (위젯 기반, 커스터마이징)
- 차트 다양성 (라인, 바, 파이, 산점도, 히트맵)

## 21. 산업별 공통 안티패턴

| 안티패턴 | 영향받는 산업 | 해결 |
|---------|-------------|------|
| 로딩 없는 빈 화면 | 전체 | 스켈레톤/스피너 필수 |
| 에러 메시지 기술 용어 | 전체 | 사용자 언어로 작성 |
| 모바일 가로 스크롤 | 전체 | 반응형 검증 필수 |
| 색상만으로 상태 구분 | 전체 | 아이콘 + 텍스트 추가 |
| 데이터 없는 빈 상태 무시 | SaaS, CRM | 온보딩 안내 제공 |
| 무한 스크롤 + 푸터 접근 불가 | 이커머스, 소셜 | 푸터 정보를 다른 곳에도 배치 |
| 자동 재생 비디오 + 소리 | 미디어, 교육 | 음소거 기본, 명시적 재생 |
| 결제 전 숨겨진 비용 | 이커머스, 여행 | 총 비용 조기 공개 |
