# 타이포그래피 백과사전

## 1. 폰트 분류

### 1.1 Serif (세리프)
글자 끝에 장식(세리프)이 있는 글꼴. 전통적, 격식, 신뢰감.

| 폰트 | 특성 | 용도 |
|------|------|------|
| Playfair Display | 고급, 클래식 | 럭셔리, 미디어, 매거진 제목 |
| Merriweather | 가독성 높음 | 본문, 블로그, 뉴스 |
| Lora | 부드러운 세리프 | 블로그, 웰니스, 문학 |
| Source Serif 4 | 깔끔한 세리프 | 학술, 공공, 기업 |
| Noto Serif KR | 한글 세리프 | 한국어 제목, 에디토리얼 |

### 1.2 Sans-serif (산세리프)
장식 없는 깔끔한 글꼴. 현대적, 명확, 범용.

| 폰트 | 특성 | 용도 |
|------|------|------|
| Inter | 가장 범용적 UI 폰트 | 모든 UI, SaaS, 대시보드 |
| Pretendard | 한국어 최적화 | 한국어 UI 전체 |
| Noto Sans KR | Google 한글 표준 | 범용 한국어 |
| Spoqa Han Sans Neo | 깔끔한 한글 | 모바일, 앱 |
| Plus Jakarta Sans | 둥근 기하학적 | 스타트업, 모던 |
| DM Sans | 기하학적 산세리프 | 테크, SaaS |
| Poppins | 둥근 현대적 | 랜딩, 마케팅 |
| Manrope | 반둥근 산세리프 | 대시보드, 앱 |
| IBM Plex Sans | 기술적 정확 | 개발자 도구, B2B |

### 1.3 Monospace (모노스페이스)
모든 글자의 폭이 동일. 코드, 데이터, 기술적 콘텐츠.

| 폰트 | 특성 | 용도 |
|------|------|------|
| JetBrains Mono | 리가처 지원 | 코드 에디터, 기술 |
| Fira Code | 인기 코딩 폰트 | 코드, 터미널 |
| IBM Plex Mono | 깔끔한 모노 | 데이터, 코드 |
| Source Code Pro | Adobe 모노 | 코드, 인라인 코드 |
| D2Coding | 한글 모노스페이스 | 한국어 코드 |

### 1.4 Display (디스플레이)
큰 크기에서 임팩트를 주는 글꼴. 제목, Hero 텍스트 전용.

| 폰트 | 특성 | 용도 |
|------|------|------|
| Outfit | 기하학적, 현대적 | Hero 텍스트, SaaS 랜딩 |
| Space Grotesk | 미래적, 테크 | 테크 랜딩, 스타트업 |
| Syne | 예술적, 독특 | 크리에이티브, 미디어 |
| Cabinet Grotesk | 그로테스크 | 브랜딩, 대형 타이틀 |

### 1.5 Script / Handwriting (필기체)
손글씨 느낌. 극히 제한적으로 사용.

- 본문에 절대 사용하지 않는다
- 로고, 인용문, 장식적 요소에만 사용
- 크기 24px 이상에서만 사용

## 4. 타입 스케일 (Type Scale)

### 4.1 스케일 비율

| 스케일 이름 | 비율 | 적합 용도 |
|-----------|------|----------|
| Minor Second | 1.067 | 매우 좁은 스케일, 앱 UI |
| Major Second | 1.125 | 좁은 스케일, 모바일 앱 |
| Minor Third | 1.200 | 적당한 스케일, 대시보드 |
| Major Third | 1.250 | 범용, SaaS, 웹앱 |
| Perfect Fourth | 1.333 | 넓은 스케일, 마케팅, 블로그 |
| Augmented Fourth | 1.414 | 넓은 스케일, 에디토리얼 |
| Perfect Fifth | 1.500 | 매우 넓은 스케일, 랜딩 |
| Golden Ratio | 1.618 | 극적 스케일, Hero |

### 4.2 실용 타입 스케일 (Major Third 1.250 기준, base: 16px)

| H3 | 28px (1.75rem) | 600 | 1.25 | 서브섹션 |
| H4 | 22px (1.375rem) | 600 | 1.3 | 카드 제목 |
| H5 | 18px (1.125rem) | 600 | 1.35 | 작은 제목 |
| H6 | 16px (1rem) | 600 | 1.4 | 라벨 제목 |
| Body L | 18px (1.125rem) | 400 | 1.6 | 큰 본문 |
| Body | 16px (1rem) | 400 | 1.6 | 기본 본문 |
| Body S | 14px (0.875rem) | 400 | 1.5 | 작은 본문 |
| Caption | 12px (0.75rem) | 400 | 1.4 | 캡션, 주석 |

## 5. 줄 높이 공식 (Line Height)

### 5.1 기본 규칙

| 용도 | Line Height | 이유 |
|------|------------|------|
| Display (40px+) | 1.0~1.1 | 큰 텍스트는 좁은 행간 |
| H1~H2 (28~44px) | 1.1~1.2 | 제목은 밀착 |
| H3~H6 (16~28px) | 1.25~1.4 | 작은 제목은 약간 넓게 |
| Body (14~18px) | 1.5~1.75 | 본문은 넉넉하게 |
| Caption (10~12px) | 1.3~1.5 | 작은 텍스트는 적당히 |

### 5.2 공식
```
최적 Line Height = 1 + (2 / Font Size)
예: 16px → 1 + (2/16) = 1.125 → 실제로는 1.5~1.6 사용 (가독성)
```

실무에서는 공식보다 아래 값을 사용:
- 제목: 1.1~1.3
- 본문: 1.5~1.75
- UI 요소 (버튼, 라벨): 1.2~1.4

## 6. 글자 간격 (Letter Spacing)

| 크기/용도 | Letter Spacing |
|----------|---------------|
| Display (48px+) | -0.03em ~ -0.02em |
| H1 (36~48px) | -0.02em ~ -0.01em |
| H2~H3 (24~36px) | -0.01em ~ 0em |
| Body (14~18px) | 0em (기본값) |
| Caption (12px) | 0em ~ 0.01em |
| Overline (10~12px) | 0.05em ~ 0.1em |
| Uppercase 텍스트 | 0.05em ~ 0.1em (필수) |
| 한국어 | 0em ~ -0.02em |

**규칙:**
- 크기가 커질수록 글자 간격을 좁힌다 (네거티브)
- 크기가 작을수록 글자 간격을 넓힌다
- 대문자(uppercase)에는 반드시 양수 letter-spacing
- 한국어는 기본값(0) 또는 약간 좁게 (-0.01em)

```css
.display { letter-spacing: -0.025em; }
.heading-1 { letter-spacing: -0.02em; }
.heading-2 { letter-spacing: -0.01em; }
.body { letter-spacing: 0; }
.caption { letter-spacing: 0.01em; }
.overline { letter-spacing: 0.08em; text-transform: uppercase; }
```

## 7. 반응형 타이포그래피

### 7.1 clamp() 함수

```css
/* clamp(최소값, 선호값, 최대값) */

h1 {
  font-size: clamp(2rem, 5vw + 1rem, 3.5rem);
  /* 최소 32px, 뷰포트에 따라 증가, 최대 56px */
}

h2 {
  font-size: clamp(1.5rem, 3vw + 0.75rem, 2.25rem);
  /* 최소 24px, 최대 36px */
}

h3 {
  font-size: clamp(1.25rem, 2vw + 0.5rem, 1.75rem);
  /* 최소 20px, 최대 28px */
}

body {
  font-size: clamp(0.875rem, 1vw + 0.5rem, 1.125rem);
  /* 최소 14px, 최대 18px */
}
```

### 7.2 Fluid Typography 공식

```
font-size = min-size + (max-size - min-size) × ((viewport - min-viewport) / (max-viewport - min-viewport))

CSS 변환:
font-size: calc(min-size + (max-size - min-size) * ((100vw - min-viewport) / (max-viewport - min-viewport)));
```

### 7.3 브레이크포인트별 타입 스케일

```css
/* 모바일 (375px) */
@media (max-width: 767px) {
  :root {
    --font-display: 2.25rem;  /* 36px */
    --font-h1: 2rem;          /* 32px */
    --font-h2: 1.5rem;        /* 24px */
    --font-h3: 1.25rem;       /* 20px */
    --font-h4: 1.125rem;      /* 18px */
    --font-h5: 1rem;          /* 16px */
    --font-body: 1rem;        /* 16px — 모바일 최소 */
    --font-body-sm: 0.875rem; /* 14px */
  }
}

/* 태블릿 (768px~1023px) */

  :root {
    --font-display: 2.75rem;  /* 44px */

    --font-h2: 1.75rem;       /* 28px */

  }

/* 데스크톱 (1024px+) — 기본값 사용 */
```

## 10. 폰트 성능 최적화

### 10.1 font-display

```css
@font-face {
  font-family: 'Pretendard';
  src: url('...') format('woff2');
  font-display: swap; /* 시스템 폰트 먼저 보여주고 로드 후 교체 */
}
```

| 값 | 동작 | 적합 |
|---|------|------|
| swap | 즉시 시스템 폰트 → 로드 후 교체 | 본문 폰트 |
| optional | 빠르면 교체, 아니면 시스템 폰트 유지 | 성능 중시 |
| fallback | 100ms 대기 → 시스템 폰트 → 3초 내 교체 | 균형 |

### 10.2 Preload

```html
<!-- 가장 중요한 폰트만 preload -->
<link rel="preload" href="/fonts/pretendard-variable.woff2"
  as="font" type="font/woff2" crossorigin>
```

### 10.3 서브셋

```css
/* 한국어 서브셋 (자주 쓰는 2,350자만) */
@font-face {
  font-family: 'Noto Sans KR';
  src: url('NotoSansKR-Regular-subset.woff2') format('woff2');
  unicode-range: U+AC00-D7AF, U+0020-007E; /* 한글 + ASCII */
}
```

## 11. 타이포그래피 안티패턴

| 안티패턴 | 문제 | 해결 |
|---------|------|------|
| 3개 이상 폰트 사용 | 일관성 파괴, 로딩 느림 | 최대 2개 (제목+본문) |
| 본문 12px 이하 | 가독성 저하 | 최소 14px (데스크톱), 16px (모바일) |
| 줄당 100자+ | 읽기 피로 | max-width: 65ch |
| 양쪽 정렬 (justify) | 불규칙 단어 간격 | 좌측 정렬 사용 |
| 줄 높이 1.0~1.2 (본문) | 빽빽한 텍스트 | 1.5~1.75 |
| 밝은 배경에 밝은 글자 | 대비비 부족 | WCAG 4.5:1 확인 |
| 대문자 본문 | 가독성 80% 감소 | 대문자는 제목/라벨에만 |
| 이탤릭 한국어 | 한글에 이탤릭 불가 | 볼드 또는 색상으로 강조 |
| 문단 간격 없음 | 텍스트 덩어리 | margin-bottom: 1.5em |
| letter-spacing 없는 uppercase | 답답한 대문자 | 0.05em~0.1em 추가 |
