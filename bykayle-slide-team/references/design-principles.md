# Design Principles — ByKayle Slide Team

> 슬라이드 디자인 원칙, 안티패턴, 레이아웃 가이드

---

## 1. 핵심 디자인 원칙

### 1.1 Less is More

- 슬라이드당 핵심 메시지 **1개**
- 불릿 포인트 최대 **5개** (이상적으론 3개)
- 텍스트보다 시각 요소 우선
- 빈 공간(여백)은 디자인의 일부

### 1.2 시각적 일관성

- 전체 프레젠테이션에서 **동일한 색상 팔레트** 사용
- 폰트는 **최대 2개** (제목용 + 본문용)
- 제목 크기: 28-36pt / 본문 크기: 18-24pt / 캡션: 12-14pt
- 정렬: 좌측 정렬 기본 (가운데 정렬은 제목 슬라이드에서만)

### 1.3 60-20-20 색상 전략

```
┌─────────────────────────────────┐
│         60% 배경/기본색          │ (흰색, 밝은 회색 등)
│  ┌─────────────┐                │
│  │  20% 주색    │                │ (브랜드 컬러, 텍스트)
│  │  ┌────┐     │                │
│  │  │20% │     │                │ (강조색, CTA, 포인트)
│  │  │강조│     │                │
│  │  └────┘     │                │
│  └─────────────┘                │
└─────────────────────────────────┘
```

### 1.4 레이아웃 다양성

- **같은 레이아웃 2번 연속 사용 금지**
- 3슬라이드마다 레이아웃 변화 권장
- "블렌더" 슬라이드 삽입 (전체 이미지, 인용구, 데이터 포인트 하나)

## 2. 슬라이드 타입별 디자인 가이드

### 2.1 제목 슬라이드 (Title)

```
┌────────────────────────┐
│                        │
│                        │
│    [큰 제목 텍스트]     │
│    [부제목 / 날짜]      │
│                        │
│              [로고]     │
└────────────────────────┘
```

- 제목: 36-44pt, Bold
- 부제목: 18-24pt, Regular
- 배경: 브랜드 컬러 또는 고품질 이미지
- 요소 최소화 (제목 + 부제목 + 로고만)

### 2.2 콘텐츠 슬라이드 (Content)

```
┌────────────────────────┐
│ [제목]                  │
│────────────────────────│
│ • 불릿 포인트 1         │
│ • 불릿 포인트 2         │
│ • 불릿 포인트 3         │
│          [이미지/아이콘] │
│                        │
└────────────────────────┘
```

- 텍스트 영역: 슬라이드의 60% 이하
- 시각 요소: 최소 1개 필수
- 여백: 상하좌우 최소 0.5인치

### 2.3 비교 슬라이드 (Comparison)

```
┌────────────────────────┐
│ [제목]                  │
│────────┬───────────────│
│ Option │ Option         │
│   A    │   B            │
│ • 장점  │ • 장점         │
│ • 단점  │ • 단점         │
│        │               │
└────────┴───────────────┘
```

- 2-3 열 비교 (4열 이상 금지 — 가독성)
- 각 열의 높이/너비 동일
- 강조 열은 배경색으로 구분

### 2.4 데이터 슬라이드 (Data/Chart)

```
┌────────────────────────┐
│ [제목]                  │
│                        │
│   ┌──────────────┐     │
│   │              │     │
│   │   [차트]     │     │
│   │              │     │
│   └──────────────┘     │
│ [출처/캡션]             │
└────────────────────────┘
```

- 차트는 슬라이드의 50-70% 차지
- 데이터 레이블 직접 표시 (범례 최소화)
- 강조할 데이터만 색상 처리 (나머지 회색)
- 출처 표시 필수

### 2.5 인용 슬라이드 (Quote)

```
┌────────────────────────┐
│                        │
│   "인용 텍스트가        │
│    여기에 들어갑니다"    │
│                        │
│         — 출처          │
│                        │
└────────────────────────┘
```

- 큰 따옴표로 시작
- 인용문: 24-32pt, Italic
- 출처: 16pt, Regular
- 배경 단색 또는 미묘한 그라데이션

### 2.6 요약/결론 슬라이드 (Summary)

```
┌────────────────────────┐
│ [핵심 메시지]           │
│────────────────────────│
│ 1. 요약 포인트 1        │
│ 2. 요약 포인트 2        │
│ 3. 요약 포인트 3        │
│                        │
│ [Call to Action]        │
└────────────────────────┘
```

- 핵심 포인트 3개 이내
- CTA가 있으면 강조색 배경 + 큰 텍스트
- 연락처/다음 단계 포함 가능

## 3. 안티패턴 (절대 하지 말 것)

### 3.1 콘텐츠 안티패턴

| 번호 | 안티패턴 | 올바른 접근 |
|------|----------|-------------|
| C-1 | 텍스트로 가득 찬 슬라이드 | 핵심 메시지만, 나머지는 발표자 노트로 |
| C-2 | 문장형 불릿 포인트 | 키워드/구문으로 축약 |
| C-3 | 작은 폰트 (14pt 미만) | 최소 18pt (본문), 12pt (캡션) |
| C-4 | 제목 없는 슬라이드 | 모든 슬라이드에 제목 포함 |
| C-5 | 의미 없는 클립아트 | 콘텐츠와 직접 관련된 시각 요소만 |

### 3.2 디자인 안티패턴

| 번호 | 안티패턴 | 올바른 접근 |
|------|----------|-------------|
| D-1 | 4가지 이상 색상 동시 사용 | 60-20-20 규칙 준수 |
| D-2 | 3가지 이상 폰트 혼용 | 최대 2개 폰트 |
| D-3 | 워드아트/그라데이션 텍스트 | 단색 텍스트, 크기/굵기로 강조 |
| D-4 | 불필요한 테두리/그림자 | 최소한의 장식 |
| D-5 | 저해상도 이미지 | 최소 150 DPI, 가능하면 SVG |
| D-6 | 기울어진/회전된 텍스트 | 수평/수직만 사용 |

### 3.3 레이아웃 안티패턴

| 번호 | 안티패턴 | 올바른 접근 |
|------|----------|-------------|
| L-1 | 요소 간 불균형 여백 | 균일한 여백 또는 의도적 비대칭 |
| L-2 | 중앙 정렬 남용 | 좌측 정렬 기본, 제목만 중앙 |
| L-3 | 슬라이드 번호 없음 | Q&A 대비 슬라이드 번호 포함 |
| L-4 | 로고 과도 노출 | 제목/마지막 슬라이드에만 |

## 4. CJK (한중일) 텍스트 특별 규칙

### 4.1 길이 조정

- 한국어/중국어/일본어 텍스트는 영어 대비 **약 2배 공간** 차지
- 영어 기준 40자 = 한국어 기준 20자로 계산
- 불릿 포인트: 영어 60자 제한 → 한국어 30자 제한

### 4.2 폰트 고려

- CJK 폰트는 영어 폰트와 **행간이 다름** — line spacing 120-140% 권장
- 볼드체는 CJK에서 가독성이 떨어질 수 있음 — 크기나 색상으로 대체 강조
- 글자별 애니메이션 금지 — 문장/단어 단위 애니메이션만

### 4.3 혼합 텍스트

- 한영 혼합 시: 영어 단어 앞뒤에 반각 공백
- 숫자 앞뒤에 반각 공백
- 괄호: 전각 괄호（）→ 반각 괄호() 통일

## 5. 접근성 체크리스트

| 항목 | 기준 |
|------|------|
| 색상 대비 | WCAG AA 기준 4.5:1 이상 |
| 이미지 대체 텍스트 | 모든 이미지에 alt text |
| 읽기 순서 | 탭 순서가 논리적 흐름과 일치 |
| 폰트 크기 | 최소 18pt (본문) |
| 색상 의존 금지 | 색상만으로 정보 구분하지 않음 (패턴/라벨 병행) |
