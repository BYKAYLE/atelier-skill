# 엣지 케이스 처리

## 템플릿이 너무 복잡할 때 (50+ 슬라이드)
- 고유 레이아웃만 추출하여 분석 (중복 제거)
- "레이아웃 {N}개를 발견했어요. 주로 사용할 것을 골라주세요."

## 콘텐츠가 너무 적을 때
- Slide Planner가 보충 콘텐츠 제안
- "내용이 좀 적어서, 이런 내용을 추가하면 좋겠어요."

## 콘텐츠가 너무 많을 때
- Appendix 슬라이드 자동 생성
- 핵심 메시지만 메인 슬라이드에, 상세 내용은 Appendix로

## Path A에서 XML 파싱 실패
- Path B로 자동 전환 (python-pptx 디자인 빌드)
- 사용자에게 "템플릿에서 디자인을 추출할 수 없어서, 새 디자인으로 만들어드릴게요." 안내

## 애니메이션 충돌 (Path A)
- 원본 `<p:timing>`이 있으면 **보존** (inject_animation.py가 자동 스킵)
- 새 애니메이션은 기존 애니메이션 없는 슬라이드에만 추가
- 충돌 감지 시 AskUserQuestion으로 확인

## 파일 크기 초과 (15MB+)
- 미디어 파일 JPEG 압축 (quality=60)
- 불필요한 미디어 파일 제거
- 그래도 초과 시 사용자에게 알림
